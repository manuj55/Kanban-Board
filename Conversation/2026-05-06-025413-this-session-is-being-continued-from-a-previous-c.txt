  2. server/src/routes/auth.ts (NEW)

  Endpoints:

  POST /api/auth/register
    Body: { email, password, name }
    Validation: email format, password min 6 chars, name required
    Flow:
      1. Check if email already exists → 400 "Email already in use"
      2. Create user (password auto-hashed by pre-save hook)
      3. Generate JWT, set httpOnly cookie
      4. Return: { user: { _id, email, name, createdAt }, message: "Account 
  created" }

  POST /api/auth/login
    Body: { email, password }
    Flow:
      1. Find user by email (case-insensitive)
      2. Compare password with bcrypt → 401 "Invalid credentials"
      3. Generate JWT, set httpOnly cookie
      4. Return: { user: { _id, email, name, createdAt }, message: "Logged in" }

  POST /api/auth/logout
    Flow:
      1. Clear httpOnly cookie
      2. Return: { success: true, message: "Logged out" }

  GET /api/auth/me
    Middleware: requireAuth (verify JWT from cookie)
    Flow:
      1. Get userId from req.user (set by middleware)
      2. Find user by id, exclude password field
      3. Return: { user: { _id, email, name, createdAt } }
